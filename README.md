I'm Dnydd, formerly known as dklyntly. Modding is my hobby, and I enjoy making useful tools and new ways to play.

My projects range from character appearance tools for Cyberpunk 2077 to randomizers, OneBlock progression, and modpacks for Minecraft.

## My projects

| Project | What it does |
| --- | --- |
| [Character Preset Manager (CET)](https://github.com/DKLYNTLY/Character-Preset-Manager-CET-) | Save, load, organize, and share Cyberpunk 2077 appearances, with backups and recovery. |
| [AutoEMC](https://github.com/DKLYNTLY/autoemc) | Fill missing ProjectE EMC values with configurable scans and diagnostic reports. |
| [Randomized Recipes](https://github.com/DKLYNTLY/Randomized-Recipes-) | Shuffle Minecraft recipe outputs with saved seeds and configurable filters. |
| [Randomized Block & Mob Drops](https://github.com/DKLYNTLY/Randomized-Block-Mob-Drops) | Randomize block and mob loot, then use commands to find the items you need. |
| [One Block Re:forged](https://github.com/DKLYNTLY/oneblockreborn) | Add native OneBlock progression, custom phases, mobs, and traders. |
| [Void One Block](https://github.com/DKLYNTLY/Void-One-Block) | Start above the void with biome identity and optional companion-mod support. |
| [Random Item Generator Resurrected](https://github.com/DKLYNTLY/Random-Item-Generator-Resurrected) | Break regenerating blocks for random items, entities, enchanted books, or chest loot. |
| [Modded Oneblock Skyblock](https://github.com/DKLYNTLY/Modded-Oneblock-Skyblock) | Build a skyblock island with quests, automation, magic, exploration, and bosses. |
